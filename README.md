One line, in the voice of a hardware wallet that will not sign a transaction at 3 AM:

> It's 3 AM. My seed phrase is asleep, my buttons have unionized, and the last thing I signed at this hour was a monkey JPEG. Come back when the sun is up and so is your judgment.

## Run it

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt` (177 characters, stdlib only, no network).
